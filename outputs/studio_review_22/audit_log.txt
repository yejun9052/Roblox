새로 확인한 도구 (Studio 내장 MCP)
- upload_image: 로컬 HTTP(127.0.0.1:34999) 의 PNG 를 Roblox 이미지 에셋으로 업로드 → rbxassetid. Import 창 없이 텍스처 사용 가능.
  한 번에 15장 올리면 120초 넘어 백그라운드로 넘어감(결과는 정상). 가끔 500 오류 → 그 장만 다시.
- generate_mesh: AI 메시(텍스처 포함 MeshPart 1개, 스크립트 없음). 품질 좋음. 연속 8건 이상이면 "Too Many Requests" 실패 → 2~5건씩.
  생성물은 Y축 -150° 돌아가 있음 → 회전 0 으로 바로잡고 크기 지정.
- generate_material: Studio 내부 오류(MaterialGenTool:210 assert)로 사용 불가.
- loadstring: execute_luau 에서 사용 가능 → 키트 소스를 HTTP 로 받아 실행.
- 스카이박스 면 방향(색 시험): Ft=-Z, Lf=+X, Bk=+Z, Rt=-X, Up=위(이미지 위쪽=+X, 오른쪽=-Z).
